# BlendKeys Blender Add-on

This folder contains a Blender add-on that shows the same favorites saved by the BlendKeys desktop app.

It reads favorites from:

```text
%APPDATA%\BlendKeys\favorites.json
```

## Install

In Blender:

1. Open `Edit > Preferences > Add-ons`.
2. Click `Install...`.
3. Choose `release\BlendKeys-Blender-Addon.zip`.
4. Enable `BlendKeys Favorites`.

## Use

- Press `Ctrl + Alt + F` in Blender to open the favorites popup.
- Click `BlendKeys` in the 3D Viewport header.
- Open the 3D Viewport sidebar with `N`, then use the `BlendKeys` tab.
- Open `View > BlendKeys Favorites`.
